# Tic-Tac-Toe Game

A simple, interactive, two-player Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. Players take turns marking X and O on a 3×3 grid. The game automatically detects wins and draws and includes score tracking and restart functionality.

## Features

- 🎮 Two-player gameplay
- ❌ X and O alternate turns automatically
- 🏆 Automatic winner detection for rows, columns, and diagonals
- 🤝 Draw detection when all cells are filled without a winner
- 🔄 Restart game functionality
- 📊 Score tracking for both players
- ✨ Winning combination highlighting
- 📱 Responsive design for different screen sizes
- 🚫 Prevents selecting an already occupied cell

## Technologies Used

- **HTML5** — Game structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Game logic, turn management, and win detection

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start playing with another player.

No additional installation or dependencies are required.

## How to Play

1. Player X takes the first turn.
2. Player O plays next.
3. Players continue taking turns until one player gets three matching symbols in a row, column, or diagonal.
4. If all nine cells are filled and nobody wins, the game ends in a draw.
5. Click **Restart Game** to play another round.
